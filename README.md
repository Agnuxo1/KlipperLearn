# KlipperLearn

**Give an old 3D printer a smarter future — with an old phone.**

Phone-first, open-source, evidence-based calibration for compatible legacy 3D printers. The target is an Android phone hosting Klipper over USB, with an HTML interface, camera and sensor evidence, and two advisor modes: local analysis or optional external multimodal review.

Publication status: research foundation. The existing workspace source has not yet been imported. No finished Android host, trained visual model or automatic printer controller is claimed by this initial publication.
