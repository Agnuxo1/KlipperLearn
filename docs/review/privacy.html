Privacy and scope

KlipperLearn Calibration Review 1.0.0. Publisher: Francisco Angulo de Lafuente.

This free application reads only session files you select. It does not transmit their contents, read browsing history, capture images or sound, connect to a printer, call an AI service, advertise or collect analytics. It stores loaded data in page memory, not localStorage or a server. It saves JSON files only after a click. Saved files are under your control.

The browser extension contains all execution code and does not request website, history, camera, microphone, download or native-messaging permissions. Its button opens its own bundled reviewer, not an outside promotional site. The website version loads public assets from GitHub Pages; GitHub and your browser retain their own network/update policies.

Offline use of the website is optional. Its service worker caches only a fixed list of public application assets inside this app's scope. It does not cache selected JSON files or contact external services. Remove the offline copy with the app button or your browser's site-data controls.

The reference algorithm checks declared trial records and suggests bounded experiments for human review. It does not inspect photographs, prove physical safety, create the separate three-mode Orca presets, perform neural inference or improve a printer automatically. Separate AI services used manually have their own pricing, eligibility, limits and privacy policies.

Keep personal data, credentials and identity documents out of input files. Neither the publisher nor this helper can delete data that you later choose to share with another provider. No account is required by this application. Source code and support: Agnuxo1/KlipperLearn on GitHub. This wrapper and its original reference engine retain the included MIT license; the main application has separate GPL notices.
