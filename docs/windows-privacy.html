KlipperLearn Slicer Review: Windows and web privacy notice

Publisher: Francisco Angulo de Lafuente. Updated 17 September 2026.

This free, open-source application reviews only the slicer presets, models, original photographs and calibration records explicitly selected by the user. Those inputs are processed locally in the application tab. The application does not send them to the publisher, an AI provider or a printer.

Application hosting and installation

The Windows package uses Microsoft Edge to host the web application served from GitHub Pages. Initial loading and application updates retrieve public program files over HTTPS. GitHub and Microsoft process their own hosting, browser and Store requests under their applicable policies; these requests can include ordinary network information such as IP addresses. The publisher does not add analytics, advertising, tracking cookies or a user database.

Optional offline support stores only public application files in the browser cache. It does not persist selected photographs or the active calibration session. Save the session explicitly before closing. Downloaded files are stored where the user chooses and remain under the user's control.

AI review and permissions

AI request and response exchange is manual. The application does not call an AI API. Users decide independently whether to share exported information with another provider, whose own policies then apply. The app does not inspect other websites or browser history and does not access a camera, microphone, location, USB device or printer.

The standard PWABuilder Windows package declares the capability required to launch its Edge-hosted application. It does not add a native device-control service, data collector or custom privileged program.

Your controls and support

Do not import credentials, private certificates or unrelated personal information. Closing the tab releases the active in-memory work; users can remove downloads and cached application files using their device's normal controls. There is no publisher-side account or uploaded-file database to delete.

Support: KlipperLearn issues. Do not post credentials or confidential records in public issues. For a privacy concern, ask for an appropriate private contact route without publishing sensitive details.
