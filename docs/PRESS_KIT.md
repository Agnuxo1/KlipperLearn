# KlipperLearn: community information kit

## One-sentence description

KlipperLearn is a free, open-source experimental toolkit for reviewing 3D-print
calibration evidence and generating supervised slicer-preset proposals.

## Short introduction

Keep an existing printer and improve the calibration workflow rather than replace
its electronics without evidence. KlipperLearn separates original photographs,
print logs, fixed-geometry comparisons and reviewed settings. The file-first
optimizer can generate paired Quality, Standard and Speed presets for OrcaSlicer
from acceptable repeated trials. Small external adapters support evidence handling
around Klipper, Moonraker, Cura, OctoPrint and other printing tools. A phone is
optional. The project is GPL-3.0-or-later, with separately scoped MIT reference tools.

## Images and accurate attribution

Published artwork is available in the repository's `assets` directory. The hero
and explanatory diagrams are AI-generated concepts, not device screenshots or
measurements. The retouched Benchy picture is editorial artwork; the original
source-photo pixels and provenance notes are separate. Preserve those labels.

The Flashforge Creator Pro Benchy tests were operator tuning advised by ChatGPT,
not KlipperLearn. The Anycubic 4Max Pro charts/cube experiments used the separate
KlipperLearn setup with phone and webcam. Do not combine them as one benchmark.

## Claims this preview does not make

It does not certify unattended printing, a global optimum, a specific speed gain,
universal native-slicer compatibility, a turnkey Android Klipper host, a public
ChatGPT directory listing, or endorsement by the ten upstream projects. The
reference web demonstration is the original 0.1.0 reviewer, not a cloud service
that automatically controls a printer. Original evidence and physical tests remain
necessary. Please link to the current status rather than copying obsolete claims.
