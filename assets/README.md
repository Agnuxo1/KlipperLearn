# Project images

The hero, architecture, calibration-cycle and advisor-mode images are AI-generated
concept illustrations. They are not device screenshots, measured results, or
proof of phone-only hosting. The workshop-retouched image was generated from an
author-supplied photograph and is editorial artwork, not measurement evidence.

`benchy-workshop-original.png` preserves the decoded RGB pixels of the original
author-supplied JPEG without generative editing. PNG conversion removes EXIF and
other source metadata; it does not establish the accuracy of handwritten times.
The author reports an approximately 20-minute full-layer Benchy result on an older
stock-mechanical Flashforge Creator Pro. Original print logs, slicer settings and
independent quality measurements are not bundled with this publication.

Images are supplied by the project author for this repository. Device names,
third-party product names and appearance do not imply endorsement. The manifest
records published file hashes and dimensions, not private source paths.
