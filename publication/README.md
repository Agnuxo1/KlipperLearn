# Model-platform distribution

This directory supports one accurate, non-exclusive listing per requested platform.
The downloadable coupon is useful independently of the software; the complete
project remains available from the versioned GitHub release linked in the listing.

Read [the listing](listing.en.txt), [platform state](status.json), and the
[work log](WORKLOG.md). Uploaded, publicly published, and moderation-approved
are different states. A missing URL is not an external publication.

The original coupon is unchanged. Its gallery render must be identified as a
digital rendering, not a physical photograph. Do not reuse Benchy photos as
proof that this coupon was printed. Do not add native Bambu profiles, machine
G-code, manufacturer endorsements, AI-free claims or exclusive-program terms.

Run `python tools/build_publication_kit.py --output DIRECTORY` to reproduce the
model package and its integrity report without connecting to a printer.

The complete application is GPL-3.0-or-later, with existing separately scoped
MIT components retaining their attribution. This packaging work does not change
licences or claim native Android installation or hardware certification.
