# Public ChatGPT submission kit

Target: KlipperLearn Printer Optimizer 0.6.0, **Skills only**.
Publisher: Francisco Angulo de Lafuente. No plugin fee or external account.

## Observed publication gate

On 16 September 2026 the owner-authorized browser reached the OpenAI Platform
plugin portal in the owner's account. Selecting Create plugin -> Skills only
showed: **Complete identity verification** and **You need a verified developer
identity before you can create or upload a plugin.**

No plugin draft, upload, submission ID, review, approval or public listing was
created. Do not represent this kit or a GitHub release as publication in ChatGPT.
The owner must complete identity verification through the official UI. Do not
send identity documents, verification codes or account credentials to this project
or into a chat. No API key or API credit purchase was required by this package.

## Prepared materials

- `listing.json`: descriptions, publisher, support, privacy, terms and starter prompts.
- `test-cases.json`: five positive and three negative reproducible test procedures.
- `logo.svg`: the existing project icon, not an OpenAI or printer-vendor logo.
- `../plugins/printer-optimizer/`: the complete skills-only plugin source tree.
- `../docs/PLUGIN_PRIVACY.md` and `../docs/PLUGIN_TERMS.md`: public disclosures.
- `../docs/BENCHMARK_PROVENANCE.md`: distinct real-machine/workflow attribution.

Do not submit `machine-map-private.json`, runtime archives, credentials or local
browser automation scripts. These are deliberately outside the repository.

## Owner completion after verification

1. Open https://platform.openai.com/plugins in the verified publishing organization.
2. Confirm Apps Management write access, then Create plugin -> Skills only.
3. Populate the listing from `listing.json`, select the actual verified identity,
   and verify every public support/policy URL loads before submission.
4. Upload the complete final skill tree and its referenced helper/STL/resources.
   Use the portal's accepted bundle layout; do not supply an invented MCP URL.
5. Add the supplied prompts and eight test cases. Record an actual installed
   ChatGPT acceptance test; local helper/browser tests do not replace it.
6. Review countries, publisher disclosures and policy attestations yourself.
7. Select Submit for Review only when the draft is accurate and complete.
8. Retain the actual submission ID. Approval is followed by a separate Publish
   action; it is not automatic on upload, submission, GitHub push or verification.

## Cost and reach

The publisher charges nothing and the skills-only workflow needs no hosted
publisher service, separate model API or printer firmware installation. OpenAI
still determines plan eligibility, region, supported surfaces and usage limits.
Do not promise unlimited access or installation for every account. Installation
of the plugin itself is distinct from installing software on a printer.
