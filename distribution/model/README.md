# KlipperLearn original calibration-card community kit

This is an original **40 x 30 x 12 mm** calibration coupon from the public
KlipperLearn source, with 7,756 triangles. The STL is included unchanged and its
SHA-256 is recorded in `asset.json`. Source asset and software project:
https://github.com/Agnuxo1/KlipperLearn . License: GPL-3.0-or-later, preserved here.

This coupon is NOT the official 3DBenchy or the Anycubic calibration cube. It is
not a certification standard or a machine upgrade. It is one fixed geometry for
controlled comparison. No claim of a physical test of this exact binary is made.
Previous Anycubic chart photos must not be treated as this coupon's proof without
matching the geometry and trial records. No generated image replaces that proof.

## Before a physical trial

Inspect the STL in your existing slicer and retain the original scale. Select
your verified printer/nozzle/material preset; check orientation, clearances and
the sliced preview. Do not use a generic G-code file or disable protections.
Record the effective layer height, layer count, material, temperatures, line
widths, supports, infill, speeds and acceleration from the actual sliced job.
There is intentionally no universal temperature, speed or support prescription.

Print a supervised baseline, photograph the real part from repeatable viewpoints
and record defects as well as successful results. Preserve the original files.
Change one approved variable; repeat each setting before comparing it. Keep model,
layer settings and material constant. Record both print duration and total elapsed
time. A completed job does not demonstrate quality, and a faster partial model
is not comparable to a completed full model. Do not label hypothetical data as real.

The empty CSV worksheet is for record keeping; it is not automatically importable
into either KlipperLearn JSON schema. The assistant must explicitly map and check
records, identities, quality reviews and missing fields before using them.

## Upload checklist

Use `LISTING.md` as a draft, not a success claim. Include the actual STL, license,
metadata and a verified original photograph of this exact model when required.
Review native license options; never replace GPL with a non-redistributable or
exclusive license for convenience. Disclose AI-assisted creation where asked.
Do not duplicate uploads within a site, join exclusivity/reward programs, offer
paid profiles or publish the user's private printer histories. A technical project
link belongs only where the site's rules permit it, not in unrelated comments.
