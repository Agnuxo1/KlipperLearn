# Free distribution channels

A publisher-fee policy and a working product are separate requirements. No paid
account, credit purchase, subscription, advertising or exclusivity is authorized.
A build, uploaded draft, accepted submission and publicly installable listing are
tracked separately. This folder does not claim store approval.

## New deliverables

`reviewer/` holds canonical UI sources for **Calibration Review 1.0.0**, a genuine
local file-review utility for Firefox/Chromium and an opt-in offline web app. It
uses the original MIT reference engine and its `klipperlearn.session.v1` schema;
it is NOT the GPL Python three-mode preset optimizer. It supports bounded local
analysis, explicit JSON exports and validation of one-variable advisor proposals.
No AI request, browser-history access, remote executable code or printer control.

Run `python tools/build_distribution.py` to reproduce the bundles and `--check`
to verify checked-in artifacts. Firefox packages are unsigned review candidates:
normal permanent installation requires Mozilla signing. Chromium packages can be
loaded unpacked for development; a ZIP is not a store listing. Do not recommend
disabling browser security to avoid review/signing.

The web app is under `docs/review/` and can be opened without installation.
Offline caching is opt-in and caches only the fixed application shell. Installing
from a browser menu depends on that browser and platform. Microsoft Store packaging
requires an actual Partner Center app identity; no invented identity or self-signed
store-ready MSIX is included. Google Play is blocked for new accounts requiring a
registration payment. The PWA provides an independent no-publisher-fee Android route.

## Printable-model distribution

The model kit contains the canonical original STL, license notices, dimensional
metadata, proposed listing text and an empty trial
worksheet. It contains no proprietary Benchy/cube file, machine-specific G-code,
retouched success photograph, fabricated print result or promise of faster prints.
The exact included STL needs physical validation and a matching original photograph
before publication on any destination requiring them. Do not substitute earlier
photographs of different calibration charts. Keep one listing per design per site.

See `channels.json`, `listings/` and `model/` for current evidence and pending gates.
Before any submission, recheck fees, exact supported license, AI disclosure, upload
rules, required images and public identity. Never opt into exclusive models or a
non-redistributable license merely to obtain points or visibility.
