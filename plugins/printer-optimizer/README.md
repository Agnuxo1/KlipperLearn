# KlipperLearn Printer Optimizer plugin

Portable skills-only package for ChatGPT/Codex surfaces that support Agent Plugins.
Use the selected assistant and its file/code tools to review real calibration
records and generate three paired OrcaSlicer modes. No phone, cloud API key, model
weights, local printer service or firmware change is required for file exchange.
The assistant must already support file execution; that capability is not bundled.

Read `skills/printer-optimizer/SKILL.md`. This package is source for installation
and testing, not evidence of a public directory listing or approval. The parent
repository documents the optional local API/MCP route and its separate setup.

The Python helper and original coupon are bundled. The example records are
synthetic; do not import their output as a real printer profile. Native profile
export supports Orca only; other slicers receive a manually reviewed settings report.
